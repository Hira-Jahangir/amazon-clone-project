Amazon Clone Project

A front-end clone of Amazon's homepage, built using HTML and CSS.

🔗 Live Demo: [https://hira-jahangir.github.io/amazon-clone-project/]

📌 About
This project recreates the layout and visual style of Amazon's homepage as a static front-end practice project. It focuses on structuring content with HTML and styling it with CSS to match a real-world e-commerce design.

🛠️ Built With
HTML5
CSS3

📁 Project Structure
amazon-clone-project/
├── index.html
├── style.css
└── images/ (project images)

🚀 Getting Started
To run this project locally:
Clone the repository: git clone [https://github.com/Hira-Jahangir/amazon-clone-project.git]
Open the project folder
Open index.html in your browser
